# FB Helper 2.1.0

Расширение Chrome (MV3): токен, cookie и статусы рекламных кабинетов Facebook. Только чтение — в рекламе ничего не меняет.

## Установка

1. Скачать: **Code → Download ZIP** и распаковать (или `git clone`)
2. `chrome://extensions` → «Режим разработчика»
3. «Загрузить распакованное расширение» → распакованная папка (не удалять после установки)

Chrome 121+. Нужна открытая вкладка Facebook в этом профиле; рекламный токен (EAAB) — с `adsmanager.facebook.com`.

## Что умеет

- **Токен** — берёт токен с открытой вкладки FB и показывает его тип: EAAB (Ads Manager), EAAI (автоправила), EAAG (Business Manager), EAAH (Commerce Manager), EAAd (Events Manager). «Проверить» показывает профиль, приложение и права токена.
- **Cookie** — строкой или JSON для импорта в антидетект; «Токен + cookie» копирует оба значения одним блоком.
- **Кабинеты** — статус, причина блокировки, спенд за период, лимиты, пиксели; объявления со статусами и причинами отклонения.

## Безопасность и лимиты

- Запросы уходят только в `graph.facebook.com` и только по кнопке. Токен показывается, только пока он есть на открытой вкладке Facebook, и не хранится дольше сессии браузера.
- Список кабинетов обновляется не чаще раза в минуту, объявления одного кабинета — раз в 30 с. Если API вернул ошибку лимита, запросы останавливаются на 30 мин.
- Версия Graph API — `v26.0`. Когда Meta её отключит, расширение само перейдёт на новую версию, которую назовёт Graph.
